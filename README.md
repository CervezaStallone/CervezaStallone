# Hi, I'm Brian

I'm a freelance dev ([brdc.nl](https://brdc.nl)) from the Netherlands and spend a lot of my time where building automation meets home automation. Most of what I publish here talks BACnet or Modbus, or helps Home Assistant and Node-RED talk to things they don't support out of the box.

## Projects

- [Home Assistant BACnet integration](https://github.com/CervezaStallone/Home-Assistant-BACnet-integration) connects BACnet/IP devices to Home Assistant. You set it up through the GUI, without YAML, and it installs through HACS.  
  ![Stars](https://img.shields.io/github/stars/CervezaStallone/Home-Assistant-BACnet-integration?style=flat-square&logo=github&logoColor=white&label=stars&labelColor=24292f&color=24292f) ![Release](https://img.shields.io/github/v/release/CervezaStallone/Home-Assistant-BACnet-integration?style=flat-square&logo=homeassistant&logoColor=white&label=release&labelColor=24292f&color=41BDF5) ![HACS](https://img.shields.io/badge/HACS-custom-24292f?style=flat-square&logo=homeassistantcommunitystore&logoColor=white)
- [ClimateMonitor](https://github.com/CervezaStallone/ClimateMonitor) is a dashboard for the XY-MD02 Modbus sensor, with SQLite storage and psychrometric charts.
- [node-red-contrib-network-tools](https://github.com/CervezaStallone/node-red-contrib-brdc-network-tools) adds nine nodes to Node-RED for network discovery, monitoring and diagnostics.  
  ![npm downloads](https://img.shields.io/npm/dm/node-red-contrib-network-tools?style=flat-square&logo=npm&logoColor=white&label=downloads&labelColor=24292f&color=CB3837) ![Node-RED](https://img.shields.io/badge/Node--RED-nodes-24292f?style=flat-square&logo=nodered&logoColor=white)
